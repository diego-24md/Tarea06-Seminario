# 🐾 Clínica Veterinaria Prado - Proyecto Web

Este es un proyecto web desarrollado con **HTML, CSS y Bootstrap 5**, que incluye páginas de inicio, login y registro de usuarios para la Clínica Veterinaria Prado.

## 📝 Descripción

El sitio está enfocado en mostrar información básica sobre la clínica, como servicios, contacto, ubicación y más. Ideal para ser utilizado como landing page para veterinarias.

## 📌 Características

- 🌐 Página principal con navbar responsivo.  
- 📋 Sección de servicios de la veterinaria.  
- 🔒 **Login** para acceso de usuarios registrados.  
- 📝 **Registro** para crear nuevas cuentas.  
- 📱 Diseño responsivo y moderno con Bootstrap 5.  
- 📩 Footer con información de contacto y redes sociales.
